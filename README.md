# AI 办公流水线演示工作台

面向 AI 初学者的交互演示：从杂乱输入出发，体验清洗、分工、质检、交付及知识沉淀。包含收件分拣、会后跟进和数据周报三个虚构场景。所有业务数据和人物均为演示样例。

## 运行

直接打开 `dist/index.html`，或在仓库根目录运行：

```sh
python -m http.server 8000 -d dist
```

随后访问 `http://localhost:8000`。演示账号为 `demo`，密码由仓库所有者另行提供。

## 检查

```sh
node check.mjs
```

设置环境变量 `DEMO_PASSWORD` 后再运行，可额外检查登录、退出和错误密码流程。

登录校验位于浏览器端，仅用于课堂演示。它不构成真实访问控制。真实用户或敏感数据需要服务端认证。
